How to use this in InDesign
  1. Draw the glass as a horizontal rectangle and rotate it → Glass / surface rotation.
  2. Draw the incident ray as a horizontal line and rotate it → Incident ray rotation.
  3. Draw one more horizontal line and rotate it by the highlighted answer. That is the refracted ray.
  4. For the ray leaving the glass again, press Next surface and set the rotation of the second face.

Whether your tool calls clockwise or counterclockwise positive cancels out of the geometry, so the answer is right either way as long as every angle you type uses the same convention. A line rotated by x° and by x ± 180° lie on top of each other.
