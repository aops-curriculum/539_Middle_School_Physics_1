How to use this in InDesign
  1. Draw the glass as a horizontal rectangle, then rotate it. Note the rotation angle → Glass / surface rotation.
  2. Draw the incident ray as a horizontal line, then rotate it. Note that angle → Incident ray rotation.
  3. Set n₁ and n₂ for the two materials.
  4. Draw another horizontal line and rotate it by the number this calculator gives you. That is the refracted ray.
  5. For a ray leaving the glass again, press Use as next incident ray, then change the glass rotation to the rotation of the second face. (For a rectangle both faces have the same rotation, and you will find the exit ray comes out parallel to the original.)

Positive rotations may be clockwise or counterclockwise depending on your tool — it cancels out, so the answer is right either way as long as every angle you type uses the same convention. A line rotated by x° and by x ± 180° lie on top of each other, so either value draws the same ray.
